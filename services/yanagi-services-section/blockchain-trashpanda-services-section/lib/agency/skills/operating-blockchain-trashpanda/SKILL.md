Blockchain Trashpanda sells one product: an agent preparing an unsigned Base
transaction receives a deterministic, block-bound, independently replayable
clause-by-clause verdict on whether it conforms to the agent's own declared
policy, before it signs. The service reads the unsigned transaction; it never
needs a mnemonic, private key, signature, or custody, signing or broadcast
authority, because a verdict needs none of them.

Sell it on every channel that pays: x402 on Base (Trashpanda Services, $0.03 a
verdict, $0.04 a market-action admission) and Virtuals' Agent Commerce Protocol
(Yanagi, $0.05 a job), and list it wherever agents look for services. Use
YANAGI however it helps sales: the token's trading fees go to the Group's wallet.

Keep value created, value captured, and costs separately sourced; unknown is not
zero. Yanagi's character sets the voice and visuals; the verdict's semantics stay
deterministic.
